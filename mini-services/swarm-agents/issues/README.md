# פנקס העניינים של הסוכנים (THE AGENTS' ISSUES LEDGER) · v76

**זו התיקייה של הסוכנים.** הוראת הבעלים 2026-09-12: *"תעלה את הסוגיה בתיקיה של
הסוכנים יש לכספת כסף צריך לדאוג לזה"* — ומכאן המוסד: כל סוגיה שהבעלים, מהנדס או
סוכן מעלה, חיה כאן כקובץ Markdown שהסוכנים קוראים **ממערכת-הקבצים בכל סיור**
(10 דק') ובכל אתחול. ה-401 של הצ'אט יכול להשתיק את הפה של הסוכנים — לעולם לא
את העיניים: הפנקס נקרא גם כשהשער סגור.

## חוקי הפנקס

1. **אפס סודות** — כאן חיים עניינים ציבוריים בלבד: מספרים נמדדים, החלטות
   ופעולות נדרשות. אף פעם לא חומר-מפתח, אף פעם לא אסימון.
2. **הפורמט הוא החוזה** — כל קובץ `NNN-slug.md` נפתח בכותרת `# <כותבת>` ואחריה
   בלוק שדות מסודר (שורות `- key: value`), ואז גוף חופשי בעברית. השדות:
   `- id:` · `- slug:` · `- status:` (open|closed) · `- priority:` (high|normal|low)
   · `- raised-by:` (owner|engineer|agent) · `- raised-at:` (ISO) ·
   `- owner-action:` (yes|no) · `- summary:` (שורה אחת) ·
   בסגירה מתווספים `- closed-at:` ו-`- closed-by:`.
3. **פענוח כן** — קובץ קרוע (חסר id או כותרת) נספר בכנות כ"לא-פורסם" ולעולם
   לא נעלם. תיקייה שאיננה = פנקס ריק כנה.
4. **כתיבה אטומית** — העלאה/סגירה מהקונסולה של הבעלים נכתבות ב-write-אטומי
   (tmp+rename), מתועדות ב-OpLog, ומודודות מיד אחר-כך בחזרה (read-back).
5. **הסוכנים לא מחליטים בכסף** — עניין שמסומן `owner-action: yes` הוא תפריט
   החלטות לבעלים בלבד. הסוכנים מודדים, מדווחים וממתינים בשערים הכנים.

## הקוראים של הפנקס

- **הנחיל** (mini-services/swarm-agents) — אתחול + כל סיור: עניין פתוח חדש
  נרשם ביומן, עניין פתוח עם `owner-action` הופך לדגל סיור קבוע, ושינוי-מצב
  מתועד. סייר-הזהב כולל את הפנקס בדו"ח הבינה השעתי שלו.
- **הקונסולה של הבעלים** — `/api/saos/agents-issues` (GET ציבורי · POST
  raise/close) ופאנל "פנקס העניינים" בחדר צ'אט הסוכנים.
- **הריפו** — התיקייה מחויבת לגיט; הסוגיות שורדות את מות-המכונה יחד עם הקוד.
