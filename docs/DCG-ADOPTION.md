# docs/DCG-ADOPTION.md — המשמר-הבלתי-נראה (v107 · THE INVISIBLE GUARD)

> הוראת הבעלים: **"בחן כיצד ניתן לייעל את הריבונות והאוטונומיה של הסוכנים
> בעזרת זה"** — Dicklesworthstone/destructive_command_guard.
> מתועד לפי חוק-הבית 3: כל טענה כאן נמדדה בפועל במהלך הגל (2026-10-02).

## 1. הבחינה-הנמדדת (מה זה ומה מצאנו)

**dcg v0.15.2** — hook ב-Rust שתופס פקודות-הרס לפני שהן רצות, לסוכני-AI
(Claude Code, Codex, Gemini, Cursor…): SIMD sub-ms, 50+ חבילות-אבטחה,
רשימות-לבנות לפני רשימות-שחורות, סריקת-heredoc, זיהוי-הקשר (נתון ≠ ביצוע),
robot-mode (JSON טהור + stderr שקט + קודי-יציאה מתועדים), MCP-server,
allowlist-מדורג עם allow-once-מבוקר.

**נמדד-חי על המכונה שלנו (13/13 בסוללה, ~17ms לזוג-בדיקות):**

| פקודה | החלטה | חוק |
|---|---|---|
| `rm -rf /` · `rm -rf src/` | deny | core.filesystem |
| `git reset --hard` · `git push --force` · `git clean -fd` | deny | core.git |
| `find . -name '*.json' -delete` | deny | core.filesystem |
| `sqlite3 db/custom.db 'DROP TABLE users'` | deny | database.sqlite (חבילה-נוספת) |
| `git stash drop` | **warn** | core.git — תגובה-מדורגת |
| `rm -rf /tmp/x` | allow | פטור-tmp מתועד |
| `grep 'rm -rf' file.txt` | allow | זיהוי-הקשר: נתון לא ביצוע |
| `git pull --rebase` · `git add -A && commit && push` · `bash scripts/verify.sh` | allow | הזרימה שלנו שורדת |

**תפיסה-חיה במהלך האימוץ (ה-contract-האמיתי):** תיעוד-ה-ADR-002 שלהם אמר
exit-2=warn; בפועל warn יוצא **exit-0** כברירת-מחדל (exit-2 רק עם
`--fail-on warn`) — spawnSync של bun החזיר status-0 על warn והסוללה שלנו
תפסה את הפער. התיקון: שדה-`decision` ב-JSON הוא האמת-הראשונה; קודי-יציאה
רק נפילה-לאחור. (שיעור: גם כלי-מצוין נבחן-חי, לא מתוך-המסמך שלו.)

## 2. התשובה לשאלת-הבעלים: איך זה מייעל ריבונות-ואוטונומיה

**ריבונות מתרחבת רק כשטווח-הפיצוץ מוגבל.** צבא שרץ ללא-השגחה נדרש עד-היום
לאחד מהלולאה כדי שאף-טעות-קטסטרופית (rm שגוי, reset-hard, DROP TABLE) לא
תשמיד את הפלטפורמה. dcg הופך את התבניות-הקטסטרופיות-הידועות לבלתי-אפשריות
מכנית — ואז **אין סיבה לחכות**: הסוכנים מריצים את כל-השאר לבד.
זו ההשלמה הישירה של חוק-הבית 4 (אפס-המתנה): ההחלטות אצלנו; האסם אצלו.

## 3. האינטגרציה (מה נבנה)

1. **התקנה** — `install.sh --no-configure --verify` מהשיבוט המקומי (supply-chain
   נקי): בינארי ל-`~/.local/bin/dcg`, checksum-SHA256 אומת, selftest עבר.
2. **קונפיג-פרויקט בתוך-הגיט** — `.dcg.toml` (enforcement-only, auto-discovered):
   `core.filesystem · core.git · system.disk · database.sqlite · secret_disclosure`
   + heredoc-scan. כל-שיבוט של הריפו נולד עם אותה-תבנית-הגנה.
   **strict_git נדחה-מדידה** — הוא חוסם `git pull --rebase origin main`
   (חוק-הבית 6!), `git add -A`, ו-push-רגיל. הגיט הוא תעלת-האמת שלנו, לא איום.
3. **הפרימיטיב** — `src/lib/saos/guard.ts`: `guardTest` (כל-פקודה → פסק-דין),
   `guardedBash` (בדיקה→ריצה), `guardStatus` (חיות ל-peek/שער). אפס-תוכן,
   אפס-סודות ב-verdict; dcg עצמו מצנזר ערכי-סודות מהפלט (נמדד-חי:
   token-מזויף הופיע כ-`[REDACTED:github_token]`).
4. **סוללת-האמת** — `scripts/guard-selftest.ts`: 13 מקרים →
   `guard-selftest-<date>.json`; כל-אי-התאמה = exit-1.
5. **השער** — `verify.sh` שער-10 (fail-closed): deny-proof (`rm -rf /` נחסם) +
   allow-proof (`echo` עובר — המשמר לא חוסם עבודה-לגיטימית) + `.dcg.toml` קיים.
6. **הצבא** — השומר v48.2.0 משמר את revive/spawn/drill שלו (deny=אין-ריצה,
   absent=fail-open כנה + יומן `revive-guard-*`); ההרל (gate-agent) משמר את
   spawn-ה-runner; **מקור-8** בגלאי-הפערים מגייס בעצמו את צופה-הרוטציה —
   הצבא מרחיב את ההגנה של עצמו מפער-מדוד.
7. **חוק-הבית 7** (AGENTS.md) — deny=לעולם-לא-רץ; הרחבת-allowlist = קומיט
   בלבד (הרשאה נסעת בגיט, נבחנת על-ידי-אחים, אף-הרחבה שקטה).

## 4. שיעור-ה-OOM — שש-מיתות-חיות ביום-אחד, והריפוי-המבני

בזמן חיבור-השער נתפס-חי: **ריצת-השער-הכבד בתוך next-server = פצצת-OOM.**
שש-מיתות ביום (kernel global-oom, next-server ב-RSS 1.39–1.99GB, anvil
מחזיק 0.83GB מתוך 4GB). הריפוי, בשכבות:

1. **sentinel מנותק** — השער רץ רק בתהליך-עצמאי מת
   (`bun scripts/role-worker-run.ts harness-sentinel`); ה-API מצית ומחזיר;
   העדות היא קובץ, לא זיכרון-תהליך.
2. **gate-park/resume** (keeper v48.2.0: `POST :3005/park-web`/`/resume-web`,
   loopback בלבד) — השער חונה את השרת לשלבים-הכבדים, מחזיר אותו חם ל-live-api;
   חלון-החניה מדוכא-החייאה 180ש'.
3. **שער-מצטמצם** — `tsc --incremental` (32ש'→5ש') + `eslint --cache
   --cache-strategy content` (36ש'→2ש') + `NODE_OPTIONS --max-old-space-size=768`
   (נמדד: SIGKILL→pass).
4. **turbopackMemoryLimit 640MB** (next.config experimental — בבייטים;
   `turbopack.memoryLimit` נדחה-חי על-ידי ה-validator של Next 16) +
   קווי-מיחזור-שומר מכווננים-מחדש לקו-הקרנל שנמדד: mature 1500→**1250**,
   young 1790→**1350** (הקרנל הרג ב-1393 — מתחת לקו הישן).

**תוצאה-נמדדת:** verify.sh — VERDICT=pass **10/10** ב-~25ש' (לעומת 7/7
ב-40–70ש' + מיתות-שרת ב-v106), lint 36ש'→2ש', tsc 32ש'→5ש', אפס-מיתות-קרנל
מאז-החניה.

## 5. r12-key-rotation-watch — הפריט-הפתוח נסגר באותו-גל

גלאי-סף קורא **גיל-מדוד** מ-key-census מול חלונות (צפייה 720ש' · פריצה
2160ש') + סטיות-הרשאות (אפס ביט-קבוצה/עולם; סקריפט-700 עובד, מפתח-777 נתפס).
נמדד-חי ראשון: 11 קבצים · maxAge 54ש' (ok) · **5 סטיות** — כלם עותקי-staging
על `upload/` שהוא **FUSE-מאונט** (chmod מדווח הצלחה ולא נאכף — נמדד-חי:
`chmod 600` → stat עדיין 777). זו סביבה, לא פרצה שאפשר לתקן בצדנו: ההגנה
האמיתית היא בתי-הכספת הקנוניים (0600/0700 על FS אמיתי) + מעטפת-ההצפה של
המעטפות-חתומות. הצופה **מדווח ולעולם לא מסובב** — הרוטציה חומר-בעלים.
התפקיד הוצע-עצמאית (מקור-8) והופעל בזהות-אמת דרך ה-API — ונרשם active.

## 6. ה-roast הכנה של dcg

- **מצוין במה שהוא, אבל הוא hook-לסוכן-יחיד** — בנוי ל-Claude-Code-סגנון
  (settings.json + PreToolUse). אין-שכבת-צבא: אין-רישום-רול, אין-מבצע-תפקיד,
  אין-מצבת. אצלנו הוא נהיה **אסם-צבאי**: חוק-בית + פרימיטיב-ספרייה + שער
  + משמר-שומר + גלאי-גיוס-עצמי.
- **ה-ADR-002 לא מדויק** — warn=exit-2 מתועד, בפועל exit-0 בלי `--fail-on warn`.
  תפסנו-חי; ה-contract שלהם טוב, התיעוד-שלו מקדים את הקוד.
- **קונפיג-פרויקט enforcement-only זו חוכמה** — ריפו לא יכול להקל על
  האבטחה שלך, רק להחמיר. אימצנו בדיוק כך.
- **אין-כלכלה** — אין-עלות/תשואה לחסימה; אצלנו כל-verdict נושא ms וספירות
  ונכנס ל-OpLog. חסימה בלי מדידה = בירוקרטיה; חסימה נמדדת = ריבונות.
- **הרחבת-allowlist אצלם = הרשאה מקומית**; אצלנו = קומיט בגיט (חוק 7) —
  שקיפות-חוצת-סשנים, שהם לא יכולים להרשות לעצמם ככלי-נייטרלי.

## 7. מה נשאר פתוח (כנות)

- `dcg install` ל-settings-של-סשן-קודן עתידי (Claude-Code-תאימות) — לא
  הופעל-חי בסשן-הזה (ההחלטה: לא לגעת בקונפיג-הסשן-החי באמצע-גל; ההגנה
  על-הסשן-הבא היא החוק + השער, לא hook-סשן).
- חבילות cloud/k8s/containers לא הופעלו — אין בעטי-אף-אחד מהם; חבילה
  שלא-בשימוש = שטח-פוסיבל-שקרי בחינם.
- `vault-passphrase-arm` — owner-gated בעיצוב (לא נוגעים).
